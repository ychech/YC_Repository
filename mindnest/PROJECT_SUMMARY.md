## 📋 项目概述

**MindNest** 是一款 AI 原生的本地优先知识管理系统，融合 Notion 的灵活编辑、Obsidian 的链接思维和语雀的精美体验，打造真正的"第二大脑"。

### 核心价值
- 🏠 **本地优先**: 数据完全可控，无需联网即可使用
- 🤖 **AI 原生**: 从底层设计的智能系统，而非外挂 AI
- 🔗 **双向链接**: 发现知识之间的隐藏关联
- 🕸️ **知识图谱**: 可视化你的知识网络
- 👥 **团队协作**: 实时协同编辑 (CRDT)

### 关键技术选型

| 领域 | 技术 | 选择理由 |
|------|------|---------|
| **桌面框架** | Tauri | 体积小 90%、Rust 核心、安全 |
| **编辑器** | TipTap | ProseMirror 基础、协同支持 |
| **状态管理** | Zustand | 轻量、无样板、TS 友好 |
| **数据库** | SQLite | 零配置、事务安全、跨平台 |
| **向量搜索** | LanceDB | 本地优先、无需服务器 |
| **全文搜索** | Tantivy | Rust 编写、高性能 |
| **本地 AI** | candle | 纯 Rust、无需 Python |

## 🤖 AI 系统设计

### RAG 流程

```
用户查询
    │
    ├─→ 查询理解 (意图分类)
    │
    ├─→ 混合检索
    │   ├─ 向量搜索 (LanceDB)
    │   ├─ BM25 搜索 (Tantivy)
    │   └─ 图谱检索
    │
    ├─→ RRF 融合 + 重排序
    │
    ├─→ 上下文组装
    │
    └─→ LLM 生成 + 引用标注
```

### 支持的模型

| 类型 | 模型 | 大小 | 用途 |
|------|------|------|------|
| **嵌入** | bge-m3 | 2GB | 多语言语义搜索 |
| **LLM** | Phi-4 | 8GB | 本地推理 |
| **LLM** | Qwen2.5-7B | 4GB | 中文优化 |
| **重排序** | bge-reranker | 2GB | 结果精排 |
