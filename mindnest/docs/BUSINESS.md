## 2. 定价策略

### 2.1 版本矩阵

```yaml
Free (免费版):
  目标用户: 个人轻度用户、学生
  限制:
    - 知识库数量: 3 个
    - 文档数量: 无限
    - 本地 AI: 基础模型 (Phi-3)
    - 云端 AI: 50 次/月
    - 云同步: ❌
    - 协作: ❌
  目标: 用户获取、口碑传播

Pro (专业版) - $8/月 或 $60/年:
  目标用户: 重度个人用户、创作者
  功能:
    - 无限知识库
    - 本地 AI: 全部模型
    - 云端 AI: 500 次/月
    - 云同步: 1GB 端到端加密
    - 高级搜索: 语义搜索
    - 版本历史: 无限
    - 自定义主题
    - API 访问
  目标: 主要收入来源

Team (团队版) - $15/人/月 或 $120/人/年:
  目标用户: 小团队、创业公司
  功能:
    - 所有 Pro 功能
    - 团队协作空间
    - 实时协同编辑
    - 成员管理
    - 团队模板
    - 共享 AI 知识库训练
    - 管理后台
    - 优先支持
  限制:
    - 最少 2 人
    - 云存储: 10GB/人
    - 云端 AI: 2000 次/人/月

Enterprise (企业版) - 定制:
  目标用户: 中大型企业、机构
  功能:
    - 所有 Team 功能
    - 私有化部署选项
    - SSO/SAML 集成

    - 专属客户成功经理
    - 定制培训
    - API 额度无限
  定价: 年付起 $10,000/年
```

## 7. 风险与应对

### 7.1 主要风险

| 风险 | 概率 | 影响 | 应对策略 |
|------|------|------|---------|
| 大厂入场 | 中 | 高 | 专注垂直场景，建立社区壁垒 |
| AI 成本上涨 | 中 | 中 | 推进本地 AI，降低云端依赖 |
| 用户留存差 | 中 | 高 | 强化知识积累价值，提高迁移成本 |
| 开源替代 | 高 | 中 | 开放核心，通过服务盈利 |
| 数据安全事件 | 低 | 极高 | 安全优先架构，保险覆盖 |

### 7.2 退出策略

1. **IPO**: 5-7 年后，ARR > $50M
2. **收购**: 被 Notion、Microsoft、Atlassian 等收购
3. **持续经营**: 保持独立，分红模式
