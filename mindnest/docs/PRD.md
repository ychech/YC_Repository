## 1. 产品概述

### 1.1 产品定位
MindNest 是一款**AI 原生的本地优先知识管理系统**，融合 Notion 的灵活编辑、Obsidian 的链接思维和语雀的精美体验，打造真正的"第二大脑"。

### 1.2 核心价值主张
- **数据主权**: 你的知识永远属于你，本地存储，随时导出
- **AI 原生**: 不是外挂 AI，而是从底层设计的智能系统
- **无压记录**: 最小化记录阻力，最大化知识连接
- **越用越聪明**: AI 持续学习你的知识网络，提供个性化洞察

### 1.3 目标用户

| 用户群体 | 痛点 | 核心需求 |
|---------|------|---------|
| 研究员/学者 | 文献分散、笔记孤立、难以关联 | 文献管理、知识图谱、研究助手 |
| 产品经理 | 需求文档多、版本混乱、协作困难 | 结构化文档、实时协作、知识沉淀 |
| 开发者/技术博主 | 代码片段管理、技术文章写作 | 代码高亮、Markdown、发布集成 |
| 终身学习者 | 学完就忘、笔记堆积、无法内化 | 间隔重复、知识关联、智能复习 |
| 创意工作者 | 灵感易逝、素材分散、难以组织 | 快速记录、多媒体支持、情绪板 |

## 2. 功能模块详述

### 2.1 核心编辑器系统

#### 2.1.1 块级编辑器 (Block Editor)
- **基本块类型**:
  - 文本块 (支持 Markdown 快捷键)
  - 标题块 (H1-H6，可折叠)
  - 列表块 (无序/有序/待办，可嵌套)
  - 代码块 (语法高亮、行号、复制按钮)
  - 引用块 (层级嵌套、样式区分)
  - 分隔线、换行块
  
- **高级块类型**:
  - 表格块 (支持公式、排序、筛选)
  - 看板块 (拖拽排序、状态流转)
  - 日历块 (时间线视图)
  - 画廊块 (图片瀑布流)
  - 嵌入块 (网页、视频、Figma 等)
  - 数学公式块 (KaTeX 实时渲染)
  - Mermaid 图表块 (流程图、时序图等)
  - 数据库块 (类 Notion 的轻量数据库)

- **交互特性**:
  - `/` 命令面板快速插入块
  - `[[` 触发双向链接搜索
  - `@` 提及日期、人员、文档
  - 拖拽排序、跨文档拖拽
  - 分栏布局 (2-4 列)
  - 块引用 (Embed Block)
  - 块评论与讨论

#### 2.1.2 Markdown 原生支持
- 完整的 CommonMark + GitHub Flavored Markdown 支持
- 实时预览与源码模式切换
- 导入导出 Markdown 保持格式
- 自定义 YAML Frontmatter

#### 2.1.3 多媒体处理
- 图片: 粘贴上传、拖拽上传、裁剪、压缩、OCR
- 视频: 本地上传、外链嵌入、时间戳标记
- 音频: 录音、语音转文字 (Whisper)
- 附件: PDF 预览、Office 文档预览

### 2.2 知识组织系统

#### 2.2.1 工作区与知识库
```
工作区 (Workspace)
├── 知识库 A (Knowledge Base)
│   ├── 文件夹/文档
│   └── 数据库
├── 知识库 B
└── 归档知识库
```

- 工作空间隔离 (个人/工作/项目)
- 知识库级别权限控制
- 模板库与快捷创建

#### 2.2.2 双向链接系统
- `[[文档名]]` 创建链接
- `[[文档名|显示文本]]` 自定义显示
- `[[文档名#标题]]` 块级链接
- 悬停预览 (Hover Preview)
- 孤儿笔记检测
- 链接统计与热度图

#### 2.2.3 标签与属性
- 层级标签: `#概念/AI/RAG`
- 属性系统: 为文档添加自定义字段
- 属性类型: 文本、数字、日期、多选、关系、公式
- 基于属性的动态视图

#### 2.2.4 多视图系统
- **文档树**: 层级文件夹视图
- **列表视图**: 表格化展示
- **看板视图**: 状态流转
- **画廊视图**: 卡片瀑布流
- **日历视图**: 时间维度
- **图谱视图**: 关系网络

### 2.3 知识图谱系统

#### 2.3.1 全局图谱
- 2D 力导向图 (D3.js / Force Graph)
- 3D 星系图 (Three.js)
- 节点大小基于链接数量/重要性
- 聚类着色 (主题自动分组)
- 时间轴演化 (知识增长动画)

#### 2.3.2 局部图谱
- 当前文档的上下文联结
- 1-3 度邻居探索
- 最短路径高亮
- 共同邻居发现

#### 2.3.3 图谱交互
- 点击跳转、框选多节点
- 筛选 (按标签、时间、类型)
- 搜索定位
- 保存常用视角

### 2.4 AI 系统 (核心差异化)

#### 2.4.1 本地 AI 架构
```
本地 AI 层:
├── 嵌入模型 (Embedding)
│   ├── bge-m3 (多语言支持)
│   └── nomic-embed-text-v1.5
├── 小语言模型 (SLM)
│   ├── Phi-4 (14B, 本地推理)
│   ├── Qwen2.5-7B-Instruct
│   └── Gemma-2-9B-it
├── OCR 引擎
│   └── PaddleOCR / RapidOCR
└── 语音识别
    └── Whisper.cpp (多语言)
```

#### 2.4.2 智能检索 (RAG)
- **混合检索**: BM25 + 向量相似度 + 图谱关系
- **重排序 (Rerank)**: 本地轻量模型优化排序
- **引用溯源**: AI 回答标注来源文档
- **多跳推理**: 跨文档关联问答

#### 2.4.3 AI 写作助手
- **内联建议**: 打字时智能续写 (类似 Copilot)
- **指令面板**: `/ai` 唤起 AI 命令
  - 续写、润色、简化、扩写
  - 翻译 (保持术语一致)
  - 总结、提取要点
  - 转换格式 (大纲转段落等)
  - 生成思维导图
- **风格学习**: 基于用户历史文档学习写作风格

#### 2.4.4 知识洞察
- **每日回顾**: 历史上的今天、随机漫步
- **智能标签**: AI 自动建议标签
- **关联推荐**: "你可能还想看"
- **知识 Gap**: 识别知识盲区，建议补充阅读
- **主题聚类**: 自动发现知识主题
- **知识健康度**: 统计孤儿笔记、断裂链接

#### 2.4.5 研究助手
- **文献综述**: 多文档自动总结
- **对比分析**: 并排列出不同观点
- **问答验证**: 基于知识库回答事实性问题
- **知识抽取**: 自动提取实体、关系、时间线

### 2.5 剪藏与收集

#### 2.5.1 浏览器插件
- 网页剪藏 (去除广告，保留正文)
- 高亮批注 (类似 Hypothesis)
- 全文保存 (离线可读)
- 自动提取元数据 (标题、作者、日期)

#### 2.5.2 移动端速记
- 小组件快速记录
- 语音备忘录 (自动转录)
- 拍照 OCR
- 稍后阅读同步

#### 2.5.3 导入集成
- 邮件转发保存
- Slack/Discord 机器人
- 微信收藏导入
- API 接收 (Zapier/Make 集成)

### 2.6 协作功能

#### 2.6.1 实时协作
- CRDT 算法实现无冲突编辑
- 光标位置显示
- 选择区域高亮
- 离线编辑、在线合并

#### 2.6.2 评论与讨论
- 行内评论 (类似 Google Docs)
- 提及 (@username)
- 评论解决/未解决状态
- 邮件/推送通知

#### 2.6.3 权限管理
- 角色: 所有者、管理员、编辑者、评论者、查看者
- 空间级别权限
- 文档级别权限
- 分享链接 (密码、有效期、水印)

### 2.7 发布与导出

#### 2.7.1 站点发布
- 一键生成静态站点
- 自定义域名 + HTTPS
- 主题模板 (博客、文档、Wiki)
- SEO 优化、RSS 订阅
- 访客分析 (隐私友好)

#### 2.7.2 导出格式
- Markdown (保持链接)
- PDF (精美排版)
- Word (.docx)
- EPUB (电子书)
- HTML (单文件/多文件)

## 3. 非功能需求

### 3.1 性能指标
| 指标 | 目标 |
|------|------|
| 首屏加载 | < 2s (桌面端) |
| 文档打开 | < 500ms |
| 搜索响应 | < 200ms |
| AI 首字响应 | < 1s (本地) / < 3s (云端) |
| 支持文档数 | > 100,000 篇 |
| 图谱渲染 | > 5,000 节点流畅 |

### 3.2 安全与隐私
- 本地数据 AES-256 加密
- 云端同步端到端加密 (E2EE)
- 可选完全离线模式
- 零知识架构 (Zero-knowledge)

### 3.3 兼容性
- 平台: Windows 10+, macOS 12+, Linux, iOS 15+, Android 10+
- 浏览器: Chrome 100+, Safari 15+, Firefox 100+
- 移动端: 响应式 + 原生 App

## 4. 用户旅程

### 4.1 新用户 onboarding
```
1. 下载安装 (1分钟)
2. 创建第一个工作区
3. 选择使用场景模板
4. 体验 AI 导入示例数据
5. 创建第一篇笔记
6. 探索知识图谱
```

### 4.2 日常核心场景
```
快速记录场景:
快捷键唤起 → 语音/打字输入 → AI 自动标签 → 关闭

深度写作场景:
新建文档 → 块编辑 → AI 辅助写作 → 双向链接 → 发布

知识复习场景:
打开图谱 → 随机漫步 → 发现关联 → 完善笔记

研究学习场景:
剪藏网页 → AI 摘要 → 加入知识库 → 建立链接
```
