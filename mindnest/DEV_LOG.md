# MindNest 开发日志

## 问题反馈与修复记录

### 2024-03-17 用户反馈问题

**问题1: 画布/画板功能异常**
- 现象：创建画板后呈现为文档格式，而非画布/画板形态
- 原因：画板组件导入或渲染逻辑有问题
- 解决：检查 EditorPage 中画板类型的渲染逻辑

**问题2: 拖拽蓝线不显示**
- 现象：拖拽时没有出现蓝色指示线，无法排序
- 排查：
  1. 检查 `SortableDocList` 组件是否正确渲染
  2. 检查 `dragOverIndex` 和 `dragOverPosition` state 是否正确更新
  3. 检查蓝线元素的 CSS 是否正确（absolute定位、z-index等）

**问题3: 文件夹+按钮行为异常**
- 现象：点击文件夹的+按钮直接创建文档，而非展开创建菜单
- 预期：点击+应展开菜单，可以选择创建文档/子文件夹
- 解决：修改 FolderItem 的 onCreateDoc 逻辑

**问题4: 文件夹功能定位疑问**
- 说明：文件夹就是**分类组/分组**，用于组织文档
- 关系：文件夹可以包含多个文档，文档可以属于一个文件夹（或无所属）
- 层级：支持无限层级嵌套（文件夹内可以再有子文件夹）

**问题5: 视觉风格调整**
- 要求：黑色简约风格（参考样例图）
- 当前：需要调整为深色主题
